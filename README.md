# App-Vellum

> **vellum** *(noun)* — a fine, durable writing material traditionally made from prepared animal skin, historically used for manuscripts and important documents.
>
> Like its namesake, Vellum is designed for capturing thoughts quickly and preserving them with as little friction as possible.

Vellum is a lightweight (macOS) quick-note capture utility. A global hotkey opens a floating input window where text is written to disk instantly—no save step, no app switching, and minimal UI overhead compared to Notes.app or Stickies.

## Status

**Work-in-progress.** @ v.1.3.7

## What it does

* Global hotkey opens a floating note window
* Save notes instantly as you type
* No save step, no app switching
* Fast, lightweight native macOS interface
* Minimal UI, minimal overhead
