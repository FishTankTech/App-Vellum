# App-Vellum

> **vellum** *(noun)* — a fine, durable writing material traditionally made from prepared animal skin, historically used for manuscripts and important documents.
>
> Like its namesake, Vellum (the app) is designed for capturing thoughts quickly and preserving them with as little friction as possible.

Vellum is a lightweight (macOS) quick-note capture utility. A global hotkey opens a floating input window where text is written to disk instantly—no save step, no app switching, and minimal UI overhead compared to (Apple) "Notes.app" or "Stickies".

## Status

**Work-in-progress.** Current release @ V2.2.1 (STABLE)

## What it does

* Global hotkey opens a floating note window
* Save notes instantly as you type with adjustable markers (via audio + haptics)
* Can create instant "scratch paper" to use and never see again via a seperate programab hotkey.
* Inline math processer (I.e. *"340 + 89 * 1.07"* will append *"340 + 89 * 1.07 *= 458.23"** after an adjustable pause.)
* Automatic tag usage (I.e. ***"//AM"*** will divert said note into "ActivismMotorsports.md", etc...).
* Quality (Changable) timeline digest with data about your usage.
* Minimal UI, minimal overhead, and minimal size, in a Fast, lightweight, and native-like macOS interface.
