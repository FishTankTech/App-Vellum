# App-Vellum
Vellum is a lightweight (macOS) quick-note capture utility. Global hotkey triggers a floating input window; text is written to disk instantly with no save step, no app switching, and minimal UI overhead compared to Notes.app/Stickies.

## Status

🚧 **Work in progress.** Core functionality is still being built. This README will be updated with full usage instructions, screenshots, and setup steps once the app is stable.

## What it does

- Global hotkey opens a floating input window
- Text saves instantly — no save step, no app switching
- Minimal UI, minimal overhead
